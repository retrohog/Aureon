# Aureon 0.4.1

A small update with a few fixes.

## Fixes

- **Clicking ahead on the seek bar.** Jumping to a later point in a song could leave you with silence or stop the music. The new spot is now ready before the old sound is dropped, so the jump is clean.
- **Full-bleed Now Playing.** The seek bar and playback buttons were off screen in this layout. They are back.
- **Settings → Intelligence.** Opening this page no longer reads your saved API key from the Keychain, so it should not ask for a password.

Apple Silicon and Intel Macs, macOS 15 or later.
